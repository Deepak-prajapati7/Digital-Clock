# ⏰ Digital Clock Web App

A modern and interactive **Digital Clock Application** built using **HTML, CSS, and JavaScript**.  
This project includes multiple time utilities like clock, stopwatch, and timer with a clean UI and smooth animations.

---

## 🚀 Features

### 🕒 Digital Clock
- Real-time clock updates every second
- Multi-timezone support:
  - India 🇮🇳
  - New York 🇺🇸
  - London 🇬🇧
  - Tokyo 🇯🇵
  - Sydney 🇦🇺

### ⏱ Stopwatch
- Start / Stop / Reset functionality
- Accurate time tracking in HH:MM:SS format

### ⏲ Timer
- Custom time input (HH:MM:SS)
- Quick presets (5m, 10m, 25m, 1h)
- Progress bar animation
- Alert + sound when time is up

### 🎨 UI / UX
- Glassmorphism design
- Animated gradient background
- Dark / Light mode toggle 🌙☀️
- Fully responsive layout

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Animations + Flexbox + Glass UI)
- JavaScript (Vanilla JS)
